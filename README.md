# qr-file-transfer
モニターとカメラを使用してファイルを送受信します。

## 使い方
`dist/send.html`(送信側)と `dist/recv.html`(受信側)をブラウザで開きます。どちらも単一ファイルで、オフラインで動作します。

1. 送信側でファイルを選ぶと、QRコードが連続表示されます。
2. 受信側で「カメラ開始」を押し、QRコードが枠いっぱいに映るようにします。
3. 受信が完了すると、保存用のリンクが表示されます。

受信の進みが遅いときは、送信側の「密度」か「速度」を下げてください。

## しくみ
- ファイルを deflate-raw で圧縮し(小さくなるときだけ)、ファイル名などのメタ情報と合わせてブロックに分割します。
- 1周目は元のブロックをそのまま送り、2周目以降は約半数のブロックをXORした補完フレームを送り続けます。受信側は、どのフレームでも「ブロック数+数枚」読めれば復元できます。
- フレームは `[F2][ID 4B][通番 4B][ブロック数 2B][データ]` です。復元後に CRC32 で検証します。

## ビルド
`src/` を編集したあとは、依存ライブラリ(lean-qr、zxing-wasm)を埋め込んだ `dist/` を作り直します。

```bash
npm install
```

```bash
npm run build
```
